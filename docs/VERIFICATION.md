## 순정 내비

v1.6.1에서 추천의 출발지 설명이 목적지 검색어에 섞이던 문제를 수정했습니다. 에뮬레이터에서 **이재모피자 검색 결과 → 길안내 → 목적지 좌표·이름 대조 → 앱 안내 중 상태 동기화**를 확인했습니다. 이전 검사에서는 **이상은파스타**를 검색어 수정 없이 찾아 순정 내비의 메뉴·가격 상세를 확인했습니다. 해당 정보를 모아의 자체 리뷰·메뉴 데이터로 가져오는 기능은 구현하지 않았습니다.

안내 취소 콜백과 앱 상태 동기화, 앱 프로세스 재시작 뒤 최신 안내 상태·목적지가 일치할 때의 추적 복구를 확인했습니다. 단순 경로 요청 성공만으로 안내 중이나 도착 상태를 표시하지 않습니다.

v1.6.4에서는 내비 서비스가 준비된 뒤 경로 요청을 한 번 전달하도록 보완했습니다. 실제 모아의 길찾기 버튼을 눌러 순정 내비 화면 전환, 이재모피자 경로 안내, 안내 종료 버튼과 회전 안내를 확인했습니다. 준비 후 경로를 한 번 전달한 로그와 서버의 안내 중 상태도 확인했습니다. 이는 한 차례 에뮬레이터 관찰이며 성능 벤치마크나 실제 주행 검증은 아닙니다.

이 시연의 추천은 가상 부산역 출발 기준입니다. 순정 내비의 현재 위치는 시흥동에 고정되어 있어 내비 안내 시간은 추천에서 계산한 시간과 다릅니다. 해당 차이를 정상적인 출발지 연동으로 해석하지 않습니다.

### v1.6.5에서 확인한 내비 재시작

2026-11-13, 순정 내비 앱을 강제 종료한 뒤 모아에서 **길찾기 안내**를 눌러 이재모피자의 순정 안내 화면이 열리는 것을 확인했습니다. 화면 전환 후 약 59초 시점에도 내비 상태 추적 서비스가 foreground 상태를 유지했고, 모아 프로세스는 동결되지 않았으며 로컬 서버의 여정 상태는 `navigating`, 제공자는 `pleos`였습니다. 작성한 샘플 대화로 수행한 검사입니다.

이전에는 모아가 뒤로 이동한 뒤 Android가 cached process를 동결해 내비 콜백을 받지 못하는 현상이 확인됐습니다. v1.6.5는 사용자 길찾기 세션 동안 알림이 있는 전용 서비스로 콜백 수신을 유지합니다. 이 결과는 한 번의 에뮬레이터 재시작 시나리오에서 확인한 상태 유지이며 장시간 주행·모든 기기·자동 도착의 검증은 아닙니다.

취소·도착·요청 만료 시 추적 서비스 종료는 코드에 연결돼 있으나, 이번 v1.6.5 설치본의 실제 화면에서 종료까지 확인하는 검사는 아직 완료하지 않았습니다. v1.6.4의 직접 도착 확인과 샘플 저장 검증과 구분합니다.

### 남은 지도·위치 문제

시험 환경은 공식 Pleos Connect v2.1.0 revision 2와 순정 내비 `3.3.2-rc5-hotfix.3`입니다. 경로선과 안내는 나타나지만 배경 도로·건물이 비고, 순정 현재 위치가 수정구 시흥동에 머무는 현상이 남아 있습니다.

- 지도 스타일 응답은 성공하지만 관찰한 `connect_empty`에는 배경·해안선 중심의 레이어만 있었습니다. 지원되는 배경 지도 활성화·지도팩 공급 경로를 확인하지 못했습니다.
- Android GPS 입력과 순정 내비의 차량 위치 경로가 달랐습니다. 권한 변경이나 PC 임시 위치 전달만으로 순정 현재 위치가 갱신되지는 않았습니다.
- 공개 NaviHelper에서 지도 스타일·현재 위치를 쓰는 API를 확인하지 못했습니다. 공식 API의 응답 좌표를 위치 입력 기능으로 해석하지 않았습니다.

이는 조사한 에뮬레이터 환경의 결과이며 실제 차량 전체의 제약으로 단정하지 않습니다. 순정 APK·시스템 속성·권한을 우회 수정하지 않았습니다. 모아의 OSRM 도로 시간 검색 성공도 순정 지도의 복구를 의미하지 않습니다.

## 음성·Gleo

| 항목 | 확인한 범위 |
| --- | --- |
| 공식 SpeechToText | 한국어 `ON_DEVICE` 합성 문장의 최종 텍스트 수신 확인. 늦게 도착한 최종 결과 보존, 중복 방지, 저장 확인 후 대기열 제거 검사 |
| 실제 대화 정확도 | 실제 4인 탑승자의 마이크 인식률·동시 발화 정확도 미측정 |
| 좌석 | 공개 STT 결과에 발언별 좌석이 없어 자동 배정하지 않음. Gleo 세션 좌석 상태 조회는 자유 대화의 화자 좌석 증거가 아님 |
| Gleo Interface | 스키마와 기능 3개 등록 로그, 공식 action 직접 전달에 따른 추천·저장 목록 실행 확인 |
| Gleo 자연어 호출 | 호출어 인식부터 모아 명령 실행까지 성공 미확인 |
| 추천 음성 안내 | 공식 TextToSpeech 요청·상태 처리와 화면 연결 검사. 실제 가청 출력 미확인 |
| 백그라운드 받아쓰기 | Gleo 전면 전환 시 앱 마이크가 `silenced`로 전환됨. 모아 복귀 후 입력 재개 확인. Gleo가 열린 동안의 동시 녹음 성공은 아님 |

2026-11-12 시험에서는 Gleo 호출 엔진의 모델 설정 파일 오류와 모델 공급 앱의 충돌이 함께 관찰됐습니다. 두 오류의 인과관계는 확정하지 않았으며, 별도의 로그 전송 오류를 음성 인증 오류로 단정하지 않았습니다. 수정된 공식 이미지나 지원되는 모델 복구 절차는 확인하지 못했습니다.

공식 STT와 Gleo의 자연어 명령 경로는 별개입니다. 스키마 등록, 직접 action 실행, 합성 문장 전사 중 하나가 성공했다고 나머지 기능의 성공으로 취급하지 않습니다.
